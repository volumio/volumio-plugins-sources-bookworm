# volumio-lastfm-plugin
Plugin to scrobble music played in Volumio 2.x to LastFM.

Also features a similar artists/tracks function in the browse section.

Scrobbling can go to Last.fm, to ListenBrainz or to both: choose in the plugin settings ("Scrobbling service"; new installations default to ListenBrainz, existing ones keep Last.fm). ListenBrainz needs the user token from https://listenbrainz.org/settings/.

Originally written by Saiyato. Session handling fixes and ListenBrainz support by Ema82.
