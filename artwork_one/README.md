# Artwork One

A cover-led interface for Volumio: the cover of what plays fills the screen, softly blurred, and every control floats above it on frosted glass. Three faces of Now Playing (cover, info, synced lyrics), an ambient display for the player's own screen, a labelled side rail, Zones, plugin updates where you see them — and every Volumio source, setting and plugin as before.

After enabling the plugin, pick **Artwork One** under Settings → System → User Interface layout design (or press *Switch to Artwork One* on the plugin's page). The theme, the ambient display and the pins are set under Settings → Appearance while Artwork One is the active interface; the plugin keeps them on the player, for every screen it drives.

Disabling or uninstalling the plugin takes the interface out of the list and switches the player back to one of Volumio's own interfaces.

Source, issues and the full changelog: https://github.com/michaltamas/volumio-artwork-one (MIT). The `ui/` folder is the built interface; it is built from that repository with `npm run build && scripts/package.sh`.
