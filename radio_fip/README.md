# FIP Radio Plugin for Volumio

## Description

`radio_fip` is a Volumio music service plugin providing access to the FIP radio channels from Radio France.

The plugin provides:

- 13 FIP radio stations
- AAC 192 Kbps HiFi streams
- Station logos
- Track metadata (artist, title, album)
- Album artwork when available
- FIP default cover when no artwork is available

## Supported Stations

- FIP National
- FIP Electro
- FIP Groove
- FIP Hip Hop
- FIP Jazz
- FIP Metal
- FIP Nouveautés
- FIP Pop
- FIP Reggae
- FIP Rock
- FIP Sacré Français
- FIP World
- FIP Cultes

The station “FIP Sacré Français” does not display album covers or track metadata (artist, title, album) because I have not been able to find the metadataId for this station.
