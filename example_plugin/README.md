# Example Plugin

Starting point for a Volumio 4 plugin. `volumio plugin init` copies this folder.

After copying, set `onSave.endpoint` in `UIConfig.json` to `<plugin_type>/<name>` from your `package.json`.

The rules every plugin must follow are in [AGENTS.md](../AGENTS.md) and the [submission checklist](https://developers.volumio.com/plugins/submission-checklist).
